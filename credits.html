🎓 THIS IS A SCHOOL PROJECT

This website was developed as an academic requirement. It showcases a full-stack web application for K-Egg — a Korean-style egg sandwich food business located in Maysan, Valenzuela City.

The project demonstrates skills in HTML, CSS, JavaScript, Node.js, Express, and MongoDB.
